# Licensing decision

The recommended source-code license is Apache License 2.0 because it is permissive and includes
an explicit patent grant. It must be added only after the repository owner confirms who owns the
copyright and has authority to license the university/thesis work and all contributions.

Before adding `LICENSE` and `NOTICE`:

1. Confirm the copyright holder with the supervisor/university if applicable.
2. Exclude MIMIC and all derived artifacts from the grant.
3. Preserve MTS-Dialog's separate CC BY 4.0 attribution if it is used locally.
4. Add the approved holder/year to `NOTICE` and the package metadata.

Until that confirmation, this repository intentionally grants no new license.
